# جدولي (Jadwali)

منظّم دراسي ذكي للطلاب: جدول المحاضرات بكل التفاصيل، تتبع الحضور، حساب المعدل (GPA) مع تجربة "لو درجاتي..."، بطاقات المراجعة بالتكرار المتباعد، بنك أسئلة، اختبارات ومساعد ذكاء اصطناعي بيقرا مذكراتك، استيراد الجدول من أي صورة/ملف، تنبيهات تعمل وأجهزتك مقفولة، وكل ده بيعمل **أوفلاين**.

## المميزات

- الجدول الأسبوعي حتى 12 محاضرة في اليوم، مع تعديل سريع
- تتبع الحضور والمواد والمحاضرات المصرية ومعدلات الدورات
- حساب المعدل التراكمي و"ما التي تحتاجه لرفع معدلي؟"
- مراجعة البطاقات (تكرار متباعد) وبنك أسئلة والاختبار التفاعلي
- مساعد ذكاء اصطناعي يقرا PDF/عرض تقديمي ويجيب على أسئلتك
- قراءة فيديوهات YouTube: رابط المحاضرة بيتحوّل لملخص/بطاقات/سيولس، أو تسأل المساعد عن الفيديو مباشرة
- استيراد الجدول من كشف درجات مصور، وتصدير التقويم (iCal)
- إشعارات دفع بتذكيرك قبل الامتحان بساعة
- يعمل بلا إنترنت، ومزامنة بين الأجهزة عبر حساب واحد
- وضع داكن وواجهة عربي/إنجليزي كاملة

## التقنيات

Next.js 15 · React 18 · Supabase (Postgres + Auth + RLS) · PWA/Service Worker · Tailwind CSS v4 · intro.js · قابل للتركيب كتطبيق أندرويد (Trusted Web Activity)

## التهيئة (Environment)

انسخ `.env.example` إلى `.env.local` واملا القيم. **ملف `.env.local` مش بيتدفع لجيت** — ميعرفش يوصل للمتصفح أبدًا.

أهم المفاتيح:

| المفتاح | المطلوب لـ | ملاحظات |
| --- | --- | --- |
| `GEMINI_API_KEYS` / `GROQ_API_KEYS` / `OPENROUTER_API_KEYS` | ميزات الذكاء الاصطناعي | مفاتيح السيرفر فقط، تفصل بفواصل لو أكتر من واحدة |
| `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` | المصادقة والمزامنة | من إعدادات مشروع Supabase |
| `SUPABASE_SERVICE_ROLE_KEY` | روابط المشاركة وحد الحماية | سيرفر فقط |
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` + `VAPID_PRIVATE_KEY` | إشعارات الدفع | يولّدهم الأمر `npx web-push generate-vapid-keys` |
| `PUSH_CRON_SECRET` | إشعارات الدفع | نفس القيمة اللي حاططها في `push_cron_secret` بقاعدة البيانات (تحت) |
| `AI_RATE_LIMIT_PER_HOUR` | حد استهلاك الذكاء الاصطناعي | اختياري، الافتراضي 25 لكل مستخدم في الساعة |

لو سبت Supabase فاضي، التطبيق بيشتغل "local-first" كامل بمفاتيح قليلة — مناسب للتجربة بس بدون مزامنة.

## إعداد قاعدة البيانات (Supabase)

1. ابنِ مشروع جديد على supabase.com.
2. من **SQL Editor** شغّل `supabase/schema.sql` — هو اللقطة الكاملة لكل الجداول وسياسات RLS والدوال.
3. فعّل الامتدادات من **Database → Extensions**: `pg_cron` و `pg_net`.
4. شغّل `supabase/09-push-subscriptions.sql` — بيسجل جدول الاشتراكات، وجدول `push_ticks` اللي بيتتبع آخر تشغيل، و**الجدول الزمني** اللي بيبعت التذكيرات كل دقيقة. الملف بيحاول يفعّل `pg_cron`/`pg_net` لو ناقصين، وبيشيل أي جدول زمني قديم قبل ما يسجّل الجديد. بعدها حدد قيمتي الجوب:

```sql
select public.set_secret('push_api_url', 'https://<دومينك>/api/push/send');
select public.set_secret('push_cron_secret', '<openssl rand -hex 32>');
```

   وحط نفس الكلمة الثانية في Vercel كمتغير `PUSH_CRON_SECRET`. بدونها التنبيهات مش هتوصلك والتطبيق مقفول.
5. اتأكد إن الجدول الزمني شغال: افتح `https://<دومينك>/api/push/health`. لازم `jobAlive: true` و`cronSecretSet: true`، و`minutesSinceTick` أقل من 3. لو `jobAlive: false` فالجدول الزمني مش مثبّت — راجع صلاحيات التنفيذ في Supabase وشغّل الملف تاني. الـ endpoint بيقول كمان `ticksTable` و`secretsShape` و`subscriptions` و`hint` — يعني بيقول بالظبط إيه الناقص بدل ما يطلّع error غامض.
6. **افتح التطبيق مرة واحدة** بعد أول تشغيل: الاشتراك في الإشعارات بيعمله المتصفح، ولو مفتاح VAPID اتغيّر بعد ما الاشتراكات القديمة اتعملت فالمتصفح بيكتشف إن المفتاح مختلف وبيجدد الاشتراك لوحده. افتح `/api/push/health` تاني وتأكد إن `subscriptions` بقى 1 أو أكتر.
7. من **Authentication → URL Configuration** أضف `<دومينك>/reset-password` إلى Redirect URLs، وإلا رابط استعادة الباسورد بيطيح.
8. (اختياري لكن مُوصى به) تأكد إن حد الذكاء الاصطناعي شغال: الجداول والدوال في `schema.sql` موجودة، وشغّل `supabase/10-ai-rate-limit.sql` للتأكد لو قاعدة البيانات اتعملت قبل النسخة الحالية.

## النشر على Vercel

1. ادفع الكود لـ GitHub واربطه بـ Vercel (مشروع بـ Next.js).
2. انقل كل متغيرات `.env.local` لـ **Project → Settings → Environment Variables**.
3. حط المفاتيح العامة (`NEXT_PUBLIC_*`) عشان يبنوا مع الكود، والخاصة للسيرفرات فقط.
4. لا حاجة لإعداد cron في Vercel — إرسال التذكيرات بيعمله الجدول الزمني جوه Supabase بالدقيقة. عدّاد التشغيل متاح على `/api/push/health`، والنسخة المنشورة من `public/sw.js` لازم يكون فيها `jadwali-v13` أو أحدث.

## تطبيق الأندرويد (APK)

التطبيق بيتثبّت كـ **Trusted Web Activity** (TWA) بحيث يشتغل ملء الشاشة من غير متصفح. إثبات الملكية بيتم عبر `/.well-known/assetlinks.json`، وبيحتاج:

- `ANDROID_PACKAGE_NAME` — نفس حزمة الـ APK (الافتراضية `app.vercel.jadoli.twa`).
- `ANDROID_SHA256_FINGERPRINT` — بصمة SHA-256 لمفتاح توقيع الـ APK.

لو اتعمل APK بمفتاح توقيع جديد، البصمة بتتغير — حدّث القيمتين معه.
